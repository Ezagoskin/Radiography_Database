# Radiography_Database

Work with COVID-19 Radiography Database. CNN Model, Knowledge Distillation. Result: model with 97.14% accuracy, lightweight model with 96.24% accuracy.

Dataset: [https://www.kaggle.com/datasets/fabrizioravelli/retinal-oct-images-splitted](https://www.kaggle.com/datasets/tawsifurrahman/covid19-radiography-database)
